# VERUN Solana client visual baseline

Status: existing product palette, documented 2026-10-08.

Preserve the original demo's navy text (#0a2540), light lavender surface
(#f8f9fe), white background and purple accent. Use a darker purple (#5b3bc4)
for accessible links, and slate (#465d73) for secondary text. System sans and
monospace fallbacks avoid external font requests. This records the existing
visual direction; it is not a new branding exercise. No animation or dark mode
is configured. Use native semantic elements, responsive reading widths and
visible focus indicators.
